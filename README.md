# YT Music Transpose

YouTube Music(music.youtube.com)에서 재생 중인 곡의 키를 **템포는 그대로 두고 반음 단위로** 올리거나 내리는 크롬 확장 프로그램입니다. 노래를 따라 부를 때 내 음역에 맞추는 용도로 만들었습니다.

- 반음 -12 ~ +12 조절, 현재 값 표시, 0으로 리셋
- 곡의 **원키를 음원 분석으로 추정**하고, 키를 바꿀 때마다 **현재 키**를 함께 표시
- 팝업 UI + 단축키 (Alt+↑ / Alt+↓ / Alt+0), 확장 아이콘 배지에 현재 값 표시
- 곡이 바뀌거나 페이지 안에서 이동해도(SPA) 설정 유지, video 요소가 새로 생겨도 자동 연결
- 설정은 브라우저에 저장되어 다음에 열어도 유지
- 외부 라이브러리·서버 없음. 모든 처리는 브라우저 안에서만 이루어짐

## 설치 (압축해제된 확장 프로그램 로드)

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램 로드** 클릭
4. 이 저장소 폴더(`yt-music-transpose`)를 선택. `manifest.json`이 있는 폴더입니다
   (GitHub에서 받는다면 Code → Download ZIP 후 압축을 풀거나 `git clone`)
5. 퍼즐 조각 아이콘 → YT Music Transpose 옆 핀 아이콘을 눌러 툴바에 고정해 두면 편합니다

설치·업데이트 전에 이미 열려 있던 YouTube Music 탭에도 자동으로 붙습니다(팝업을 열 때도 한 번 더 확인). 그래도 팝업 상단에 "탭을 새로고침(F5)하세요"가 보이면 탭을 새로고침하세요.

코드를 수정했다면 `chrome://extensions`에서 이 확장의 새로고침(↻) 버튼을 누르면 됩니다. 이미 키를 바꿔 둔 탭은 새로고침해야 새 코드로 처리됩니다.

## 사용법

1. music.youtube.com에서 곡을 재생
2. 툴바의 확장 아이콘을 눌러 `−` / `+` 버튼이나 슬라이더로 키 조절
   - 팝업이 열린 상태에서 키보드 ↑ / ↓ / 0 도 동작
3. 또는 단축키 사용 (YouTube Music 탭이 아니어도 크롬 창이 활성 상태면 동작)

| 단축키 | 동작 |
|---|---|
| Alt + ↑ | 반음 올리기 |
| Alt + ↓ | 반음 내리기 |
| Alt + 0 | 원래 키로 |

키를 바꾸면 화면 위쪽에 "키 +2 · B♭ 메이저" 같은 알림이 잠깐 뜨고, 확장 아이콘에 현재 값이 배지로 표시됩니다(올림 빨강, 내림 파랑).

단축키가 다른 프로그램과 겹치면 `chrome://extensions/shortcuts`에서 바꿀 수 있습니다(팝업의 "단축키 변경" 링크).

### 음질 옵션

| 옵션 | 지연 | 특징 |
|---|---|---|
| 고음질 (기본) | 약 85ms | 저음·화음이 깨끗함. 따라 부르기용 기본값 |
| 저지연 | 약 43ms | 드럼 등 타격음이 조금 더 또렷함, 저음은 약간 거칠어질 수 있음 |

지연은 소리가 영상·가사 표시보다 늦게 나오는 정도입니다. 녹음이 아니라 따라 부르기 용도라면 체감하기 어려운 수준입니다.

## 알아둘 점

- **처음 키를 바꿀 때 한 번 페이지 클릭이 필요할 수 있음**: 크롬은 사용자가 페이지를 한 번이라도 클릭하기 전에는 웹 오디오를 시작하지 못하게 막습니다. 곡을 재생하려고 이미 클릭했다면 바로 적용되고, 아니면 "페이지를 한 번 클릭하면 키 변경이 적용됩니다" 알림이 뜹니다.
- **0반음에서는 원음 그대로**: 원래 키일 때는 피치 시프터를 거치지 않고 원음이 지연 없이 그대로 나갑니다. 키를 바꾸는 순간 짧게 교차 페이드되며 피치 시프터 경로로 넘어갑니다.
- **목소리 음색 변화**: 피치를 옮기면 보컬의 음색(포먼트)도 같이 옮겨집니다. ±3반음 정도까지는 자연스럽고, 크게 옮길수록 높이면 가늘게, 낮추면 굵게 들립니다.
- 같은 페이지의 오디오를 가로채는 다른 확장(이퀄라이저, 볼륨 부스터 등)과 동시에 쓰면 둘 중 하나가 동작하지 않을 수 있습니다. 이 경우 팝업 상단에 "영상 요소 연결 실패"가 표시됩니다.

## 동작 원리

```
<video> ─ source ─┬─ dry gain ──────────────────────▶ 스피커   (원래 키, 지연 없음)
                  ├─ 피치 시프터(AudioWorklet) ─ wet gain ─▶ 스피커   (키를 바꿨을 때만 연결)
                  └─ AnalyserNode ─▶ 원키 추정
```

- `src/content.js`: music.youtube.com 페이지에 주입. 재생이 시작되면 `AudioContext`를 만들고 페이지의 `<video>`를 Web Audio 그래프로 연결. MutationObserver와 `play` 이벤트로 새로 생기는 media 요소도 자동 연결. 원래 키(dry)와 피치 시프트(wet) 경로를 교차 페이드로 전환
- `src/key-detect.js`: 원키 추정. 스펙트럼 피크를 12개 음이름(크로마)으로 모아 곡 전체에 누적하고, 24개 장·단조 프로파일(Temperley 프로파일에 배음 성분 반영)과 상관관계가 가장 높은 조를 고름. 저음역 크로마를 따로 가중. 곡이 바뀌면 자동 초기화
- `src/pitch-worklet.js`: 오디오 스레드에서 도는 피치 시프터. Laroche-Dolson 방식의 **피크 고정 위상 보코더(phase vocoder)**
  - STFT(Hann 창, 4096 또는 2048 샘플, 8배 중첩)로 스펙트럼을 구한 뒤, 스펙트럼 피크마다 주변 영역을 통째로 목표 주파수로 옮기고, 프레임 사이 위상이 새 주파수에 맞게 이어지도록 회전
  - 좌우 채널에 같은 위상 회전을 적용해 스테레오 이미지 유지
  - 드럼 같은 순간음(트랜지언트)을 감지하면 해당 영역 위상을 원래 위상으로 리셋해 타격감이 뭉개지지 않게 처리
  - 0반음일 때는 원음을 그대로 통과(수치 오차 1e-7 이하)
- `src/background.js`: 단축키 처리, 아이콘 배지 갱신
- `popup/`: 팝업 UI
- 설정(`semitones`, `quality`)은 `chrome.storage.local`에 저장되고, 모든 YouTube Music 탭이 변경을 바로 반영

## 원키 추정에 대해

- 유튜브 뮤직은 곡의 키 정보를 제공하지 않아서, 재생되는 소리를 분석해 **추정**합니다. 곡을 재생하고 10초쯤 지나면 표시되고, 오래 들을수록 안정됩니다
- 가장 흔한 오차는 **나란한조 혼동**(예: E 메이저 ↔ C# 마이너)입니다. 두 조는 조표가 같아서 구분이 어렵기 때문에 팝업에 "또는 C# 마이너"처럼 함께 표시합니다
- 실제 곡 11개(로그인 없이 일반 유튜브, 곡당 약 17~35초 분석)로 시험했을 때 정확히 맞춘 비율은 약 55%, 나란한조까지 맞은 것으로 보면 약 65%였습니다. 곡 중간 전조, 드럼·효과음 비중이 큰 곡, 인트로만 들은 경우 틀리기 쉽습니다
- 표시 키가 틀려 보여도 **키 조절 자체(반음 이동)는 정확**합니다. 현재 키는 "추정 원키 + 이동한 반음 수"로 계산합니다

## 검증 결과

**DSP 오프라인 테스트** (`test/dsp-test.js`)

```bash
node test/dsp-test.js
```

Node.js가 없으면 VS Code에 들어 있는 Node로도 실행됩니다(Git Bash 기준):

```bash
ELECTRON_RUN_AS_NODE=1 "$LOCALAPPDATA/Programs/Microsoft VS Code/Code.exe" test/dsp-test.js
```

- 사인파·화음 신호를 ±1 ~ ±12반음 이동: 목표 주파수와의 오차 0.02센트 이내, 신호 대 잡음비 약 78 ~ 89dB
- 0반음에서 원음 복원 오차 6e-8, 음량 흔들림 0.01dB, 스테레오 분리 유지
- CPU: 10초 분량 스테레오 처리에 약 0.8 ~ 1.1초 (코어 하나의 10% 내외)

**실제 브라우저 테스트**: 임시 크롬 프로필에 확장을 로드하고 실제 곡을 재생하면서, 피치 시프터 앞뒤 신호의 스펙트럼을 비교해 이동량을 측정했습니다.

| 설정 | 측정된 이동량 |
|---|---|
| +3 | +300 cents |
| -5 | -500 cents |
| 0 | 0 cents |
| +12 | +1200 cents |
| -12 | -1200 cents |
| +4 (저지연) | +400 cents |
| 다음 곡으로 넘긴 뒤 +2 | +200 cents |

- 다음 곡으로 넘어가도 설정 유지, 새로 추가된 media 요소 자동 연결 확인
- 팝업 버튼·배지·단축키 등록(Alt+↑/↓/0) 확인
- 단, 로그인하지 않은 상태에서는 한국에서 music.youtube.com 재생이 막혀 있어서, 자동 테스트는 같은 확장을 www.youtube.com에도 붙인 테스트용 사본으로 진행했습니다(오디오 처리 코드는 동일). music.youtube.com에서 귀로 듣는 최종 확인은 직접 해 주세요.
